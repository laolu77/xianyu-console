# 闲鱼卖家客服控制台

> 版本 **v2.0.0** · 更新记录见 [CHANGELOG.md](CHANGELOG.md)

一个本地运行的小工具：**自动回复买家消息**、**买家付款后自动发卡密/虚拟商品**，
并附一个网页控制台用于管理卡券、商品、回复规则和订单。

> ⚠️ **务必先读 [免责声明](#免责声明)**。本项目通过操作闲鱼官方 PC 客户端工作，
> 属于平台协议中限制的自动化行为，存在账号被限流/封禁的风险，请自行评估。

---

## 它怎么工作

```
闲鱼 PC 卖家客户端（Electron，开启 9222 调试端口）
        ▲                    │
        │ CDP（Playwright）   │ 订单卡片 / 聊天消息
        │                    ▼
   backend/engine.py ──► backend/web_engine.py（常驻引擎）
                                │
                                ▼
                        MySQL（卡券 / 商品 / 规则 / 订单）
                                ▲
                                │
              frontend/（PHP 网页控制台，浏览器访问）
                                ▲
                                │
                    app_launcher.py（桌面启动器，负责起 PHP / 引擎 / 客户端）
```

- **不改接口、不逆向协议**：引擎用 Playwright 连客户端自带的调试端口，模拟真人点击。
- **订单与会话同源**：发货判断基于**聊天窗口里的订单卡片**，不靠昵称猜会话，
  从结构上避免"发错人"。
- **卡密一次性**：每笔订单映射一份卡密，发出即标记，不重复发。

## 需要准备什么

| 依赖 | 说明 |
|---|---|
| Windows 10/11 | 引擎与客户端都跑在 Windows |
| 闲鱼 PC 卖家客户端 | 官方下载，安装后登录店铺账号 |
| MySQL 5.7+ | 存放卡券、商品、规则、订单 |
| PHP 7.3+ | 跑网页控制台（安装包内含便携版） |
| Python 3.9+ | 跑引擎与桌面启动器 |

> 本仓库**不含** PHP/Python 运行时和第三方依赖（体积太大）。
> 需要便携版可自行把 PHP、Python 放进 `runtime/php`、`runtime/python`，
> 或用安装包构建脚本 `installer/setup_gui.py` 自行打包。

## 快速开始

```bash
git clone <this-repo> xianyu-console
cd xianyu-console

# 1. 装 Python 依赖
pip install -r requirements.txt

# 2. 配数据库
cp data/db_config.example.json data/db_config.json
#   编辑 data/db_config.json，填 MySQL 地址/账号/密码/库名
#   执行建表：mysql -u root -p < frontend/init.sql

# 3. 设控制台登录密码
#   直接运行安装向导（推荐）：
python installer/setup_gui.py
#   或手动在 data/auth.json 写入：
#   {"user":"admin","hash":"<bcrypt哈希>","updated_at":"..."}

# 4. 启动
python app_launcher.py
```

启动后浏览器访问 `http://127.0.0.1:8082`，用 `admin` + 你设的密码登录。

### 生成密码哈希

```bash
python -c "import bcrypt;print(bcrypt.hashpw(b'你的密码', bcrypt.gensalt()).decode())"
```

PHP 的 `password_verify()` 能直接验证这个 `$2b$` 哈希。

## 功能一览

- **自动回复**：关键词规则匹配，命中即回；同一买家 6 小时内不重复回同一句
- **自动发货**：识别聊天里的「我已付款」订单卡 → 平台确认发货 → 发送卡密
- **定时扫描**：买家付款后不再发言也能扫到（扫会话列表的订单面板）
- **卡券管理**：卡密池、一次性发放、按商品绑定
- **订单管理**：订单与卡密映射、补发、发货状态
- **商品池**：商品与卡密捆绑定
- **内网穿透**：手机/外网浏览器也能访问控制台
- **登录保护**：密码登录 + 可选「连续失败 5 次锁 5 分钟」

## 两种实现路线：本项目为什么选 CDP

闲鱼能接入的官方渠道只有一个（开放平台），但它做不了"自动回复"。两条路线的硬差异：

| 维度 | **本项目：CDP 驱动客户端** | 官方开放平台 API |
|---|---|---|
| 原理 | Playwright 连客户端 9222 调试端口，模拟真人点击 | 调 `open.goofish.com` 的 ISV 接口 + 消息回调 |
| 申请门槛 | 无，装上就能跑 | **需企业资质 + 场景说明 + 审核 1~3 个工作日**（个人只能拿基础查询） |
| **自动回复** | ✅ 可做（读聊天窗、发消息） | ❌ **官方没有 IM 接口**，做不了 |
| 自动发货 | ✅ 可做 | ✅ 有 `goosefish.virtual.delivery`（虚拟商品） |
| 订单/退款 | ✅ 可做 | ✅ 有对应接口 |
| 必须开 PC 客户端 | ✅ 必须常驻 | ❌ 不需要，服务器跑 |
| 手机端 | 只能"遥控"PC | ✅ 原生支持 |
| 稳定性 | 中：客户端改版可能要调选择器 | 高：接口变更官方会公告 |
| 合规性 | ⚠️ 属平台协议禁止的自动化 | ✅ 走官方授权 |
| 多账号 | 难（一机一个客户端） | 容易（token 隔离） |
| 开发成本 | 已实现 | 高（OAuth2、签名、买家/卖家双 Token、回调验签） |
| 资源占用 | ~1.3GB（大头是客户端） | 很低（纯 HTTP 请求） |

**结论**：如果你只要能**自动发货**，官方 API 是更稳的合规路线（但个人资质大概率拿不到发货权限）；
只要涉及**自动回复**，就绕不开 CDP 或逆向协议——而逆向协议的封号风险比 CDP 更高。
本项目选 CDP，是在"能实现全部功能"和"不逆向协议"之间的折中。

> 官方接口清单见 [open.goofish.com 服务端接入文档](https://open.goofish.com/doc/development/dev/server.html)。

## 资源占用（Windows 实测）

各组件真实工作集（同一台机器测得，仅供估算）：

| 组件 | 内存 | 说明 |
|---|---|---|
| 闲鱼 PC 客户端 | **300~500 MB**（单窗口）<br>**1.0~1.3 GB**（多窗口/多标签） | Electron 多进程，占用最大的一部分 |
| 自动回复引擎（Python+Playwright） | 50~80 MB | 空转 32MB，连上 CDP 后上升 |
| PHP 内置服务器 | 15~30 MB | 每个请求临时进程，空闲时极低 |
| 桌面控制台 | ~48 MB | 只在启动器窗口开着时占用 |
| MySQL | 150~300 MB | 取决于 `innodb_buffer_pool_size` |
| **合计（单客户端窗口）** | **约 0.6~1.0 GB** | 8GB 内存机器可用 |

**磁盘**：

| 项 | 大小 |
|---|---|
| 本程序（解压后） | **227 MB**（PHP 69MB + Python 120MB + 代码 8MB + 依赖 30MB） |
| 闲鱼 PC 客户端 | 300~500 MB（官方安装包自带） |
| MySQL + 数据 | 视商品/订单量，通常 100MB 起 |
| **合计** | **约 700 MB ~ 1 GB** |

**CPU**：空闲时接近 0；每轮扫描（默认 180 秒一次）会短暂升到 5~15%，持续几秒到几十秒（取决于会话数量）。
把 `backend/config.yaml` 的 `poll_interval` 调大、或关掉「定时扫描」，可显著降低占用。
